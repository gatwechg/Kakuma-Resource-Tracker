# Kakuma Resource Tracker

## Overview
The **Kakuma Resource Tracker** is a web-based application designed to help manage and track community resources in the Kakuma region. It allows users to add, filter, search, and manage resources such as water points, food distribution centers, and medical aid facilities. The application is built with HTML, CSS, and JavaScript, and it uses local storage to persist data.

## Features
- **Add Resources**: Users can add resources by specifying the name, type, and location (zone).
- **Filter Resources**: Filter resources by type (e.g., water, food, medical).
- **Search Resources**: Search resources by name, type, or location.
- **Delete Resources**: Remove resources from the list.
- **Resource Counter**: Displays the total number of resources.
- **Local Storage**: Saves resources locally so they persist across browser sessions.

## Technologies Used
- **HTML**: For structuring the web page.
- **CSS**: For styling the application.
- **JavaScript**: For interactivity and functionality.
- **Local Storage**: For saving and retrieving resources.

## How to Use
1. Open the application in a web browser.
2. Use the form to add a new resource by entering the name, selecting the type, and specifying the location.
3. Use the filter buttons to view resources by type (e.g., water, food, medical).
4. Use the search bar to find resources by name, type, or location.
5. Click the delete button (`×`) on a resource card to remove it.
6. The total number of resources is displayed at the top of the page.

## File Structure
- **index.html**: The main HTML file for the application.
- **styles.css**: The CSS file for styling the application.
- **app.js**: The JavaScript file containing the application's logic.
