# Kakuma Resource Tracker

## Overview
The Kakuma Resource Tracker is a web application designed to help the Kakuma community manage and track available resources. Users can add various types of resources, such as water points, food distributions, and medical aid, and filter through the resources based on their type. The application provides a user-friendly interface for both resource management and community support.

## Project Structure
The project consists of the following files:
- `index.html`: Contains the main structure of the web application, including forms for adding resources and sections for displaying and filtering resources.
- `styles.css`: Defines the styles for the web application, including layout, colors, fonts, and overall appearance.
- `app.js`: Contains the JavaScript code that manages the functionality of the application, including adding resources and filtering the resource list.

## Setup Instructions
To set up the Kakuma Resource Tracker locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```bash
   cd Kakuma-Resource-Tracker
   ```

3. **Open `index.html` in a web browser**:
   You can simply double-click the `index.html` file or open it using your preferred web browser.

## Usage Guidelines
- **Adding Resources**: Fill in the resource name, select the resource type from the dropdown menu, and enter the location (zone) before clicking the "Add Resource" button.
- **Filtering Resources**: Use the filter buttons to view resources by type (All, Water, Food, Medical). You can also use the search input to find specific resources.
- **Viewing Resources**: The resources will be displayed in the designated section below the filters.
